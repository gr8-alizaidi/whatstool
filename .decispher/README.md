# Decispher Context Map — Demo

This folder is generated by Decispher. **Do not edit any file by hand** — your
changes will be overwritten on the next sync.

## Files

- `overview.md` — top-level project context map (start here)
- `index.json` — machine-readable topic map for AI agents
- `topics/` — per-topic context stubs (one file per topic)
- `decisions.md` — Decision Guardian alerts (strict format)
- `context-rules.json` — Decision Guardian rules (strict format)

## How to update

Edit context units in the Decispher dashboard. Approved changes auto-sync to
this folder via a Decispher pull request.

## Manual sync

Visit your Decispher dashboard and open the project's Git Sync page.
